# Рефлексивная Цифровая Персона (РЦП)

Платформа для развития системной рефлексии у школьников через диалоговое взаимодействие с ИИ-агентом.

## Структура проекта

```

├── app.py                  # Основное приложение Flask
├── config.py               # Конфигурация

├── database.py             # Инициализация БД
├── auth.py                 # Аутентификация
├── moderator_routes.py     # Маршруты модератора
├── user_routes.py          # Маршруты пользователя
├── ai_agent.py             # Логика ИИ-агента
├── templates/              # HTML-шаблоны
│   ├── base.html
│   ├── login.html
│   ├── register.html
│   ├── moderator_dashboard.html
│   ├── user_dashboard.html
│   ├── chat_session.html
│   ├── create_session.html
│   ├── edit_session.html
│   ├── view_users.html
│   ├── user_history.html
│   └── session_complete.html
└── static/                 # Статические файлы
    ├── css/
    └── js/
```

## Функционал

### Для модератора (педагога):
- Авторизация и вход в систему
- Загрузка методических материалов и контекста сессий (PDF, DOCX, TXT, MD)
- Создание сессий с диалоговыми заданиями
- Просмотр статуса всех пользователей
- Просмотр истории запросов и ответов каждого пользователя
- Управление статусами пользователей (активен/не активен/заблокирован)
- Отслеживание прогресса пользователей по сессиям

### Для пользователя (ребенка/ученика):
- Авторизация на платформе
- Получение поэтапных диалоговых заданий от РЦП
- Отправка ответов на задания
- Просмотр своей истории взаимодействий
- Отслеживание прогресса выполнения сессий

### ИИ-агент (Рефлексивная Цифровая Персона):
- Обработка загруженных модератором методических материалов
- Генерация рефлексивных ответов на основе контекста сессии
- Анализ глубины рефлексии в ответах пользователя
- Адаптация последующих вопросов на основе предыдущих ответов
- Оценка выполнения заданий и переход к следующим этапам

## Быстрый старт

```bash
# Установка зависимостей
pip install -r requirements.txt

# Инициализация базы данных
python database.py

# Запуск приложения
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Первый вход

1. Зарегистрируйте первого пользователя с ролью "Модератор"
2. Создайте сессию с диалоговыми заданиями
3. Загрузите методические материалы для сессии
4. Зарегистрируйте пользователей (учеников)
5. Пользователи могут начать работу с сессиями

## Пример создания сессии

Список заданий указывается в JSON формате:

```json
[
  {
    "description": "Опишите ситуацию, которая вызвала у вас сильные эмоции",
    "goal": "Идентификация эмоционально значимой ситуации"
  },
  {
    "description": "Какие мысли возникли у вас в момент этой ситуации?",
    "goal": "Анализ автоматических мыслей"
  },
  {
    "description": "Как вы отреагировали на эту ситуацию?",
    "goal": "Осознание поведенческих реакций"
  }
]
```

## Технологии

- **Backend**: Python + Flask
- **База данных**: SQLite (для продакшена можно PostgreSQL)
- **Аутентификация**: Flask-Login с хешированием паролей (Werkzeug)
- **ИИ-агент**: Встроенная эвристическая модель с возможностью интеграции локальных LLM (Ollama, LM Studio, etc.)
- **Frontend**: HTML5, CSS3, JavaScript (ванильный)
- **Обработка файлов**: PyPDF2, python-docx

## Интеграция с LLM

Для подключения полноценной языковой модели отредактируйте функцию `generate_reflective_response` в файле `ai_agent.py`. Поддерживаются:
- Ollama (локальные модели)
- LM Studio
- OpenAI API
- Другие совместимые API

## Безопасность

- Пароли хранятся в хешированном виде
- Защита от CSRF атак
- Валидация загружаемых файлов
- Разделение прав доступа (модератор/пользователь)
